# LLM Council 0.8.0 Release Notes

## Highlights

- Windows works with large prompts: all three CLI provider adapters (Claude
  Code, Codex, Gemini) feed the prompt via stdin instead of argv, avoiding the
  ~32KB `CreateProcess` command-line cap that failed spawns outright.
- Codex server-side rejections are no longer silent: `turn.failed` events
  (which arrive with exit code 0) now raise with the server's error message
  instead of returning an empty successful response.
- CLI adapter auth is fixed for subscription/keychain and Vertex machines:
  `--bare` is only used when `ANTHROPIC_API_KEY` is set, and the subprocess
  env allowlist keeps the identity and auth variables the CLI needs
  (`USER`, OAuth token, Vertex project/region).
- Gemini CLI headless runs no longer fail on directory trust: the adapter
  passes `--skip-trust` and runs from its empty isolated home.
- OpenRouter structured output strips number-range JSON-Schema keywords that
  routed providers reject with a 400.

## Security

- CLI subprocesses now run from empty, adapter-controlled directories instead
  of the caller's CWD. This closes two paths for attacker-controlled repos to
  influence council runs: a malicious project `.gemini/` config (MCP servers
  spawn at CLI startup once a directory is trusted) and `CLAUDE.md`
  auto-discovery prompt injection on the Claude Code non-`--bare` path.

## Breaking Changes

- Unused public symbols removed from the published package (no in-repo
  callers; import paths break if you relied on them):
  `FAST_MODEL`, `REASONING_MODEL`, `CODE_MODEL`, `CRITIC_MODEL`
  (`llm_council.providers.openrouter`), `AGENT_CLASSES`, `create_agent`
  (`llm_council.registry.base_agent`), `cleanup_old_artifacts`
  (`llm_council.storage.artifacts`), `Summarizer.get_total_tokens_saved`,
  and `ModelOverrides.get_for_provider`.

## Verification

- 451 tests pass; ruff lint/format and `mypy --strict` clean in CI.
- All three CLI adapters live-verified end-to-end post-change (each returns a
  correct answer with the prompt delivered via stdin).
- Both code changes shipped through multi-model council review gates; the
  round-2 review ran through the fixed gemini/claude adapters with zero
  provider errors.

## Upgrade Notes

- No API changes beyond the removed symbols listed above. If you imported any
  of them, vendor the values into your own code.
- Windows users previously hitting "command line too long" on large prompts
  or schema-heavy structured output should see those runs succeed unchanged.
